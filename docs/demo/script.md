# Three-minute demo

Prepare a GitHub issue you own or have permission to comment on. Save the three service credentials and connect GitHub before presenting. Run one full workflow beforehand to verify account access and latency. Keep a recording of that real run as a clearly identified fallback.

**0:00 — The problem.** “I have several AI agents, but I keep explaining the same project. ClineBrain gives them one shared brain.” Show the original 3D agent collection. Explain which two agents actually run today.

**0:20 — The memory.** Open Shared brain. Show a project constraint and its source. Start a task against the prepared GitHub issue.

**0:40 — The handoff.** Open Activity. Cline coordinates, Parallel finds current sources, and your own Codex CLI receives the same context. Open Context and point out the exact memory snapshot.

**1:30 — Real action.** Inspect the draft, optionally edit it, and approve. Open the resulting GitHub URL only after the app verifies the comment. Do not present a fixture or a pending response as a real external write.

**2:10 — It remembers.** Keep the proposed memory. Start a follow-up task and show that memory in the new task's Context. The second task need not publish another comment.

**2:40 — It repeats.** Show Issue Brief and Daily Project Brief. Configure a daily routine. Explain that the Mac and app must be running, and writes still wait for review.

**Close.** “The agent can change. Your context stays.” Show the repository, setup instructions, and the actual implemented scope.
